# Windows 桌面节日提醒贴纸 — 设计文档

## 概述

一个基于 Electron 的 Windows 桌面应用，以常驻贴纸形式显示中国节日信息和倒计时，支持自定义提醒和系统通知。

## 技术选型

- **框架**: Electron
- **存储**: electron-store（JSON 文件）
- **节日 API**: Nager.Date（免费，无需 API Key）
- **打包**: electron-builder

## 整体架构

```
  │ • API 轮询      │◄────────►│ • 贴纸窗口       │

  │ • 系统托盘      │           └──────────────────┘

  └────────┬────────┘
           │
           ▼
       ┌──────────┐    ┌──────────────┐
       │ Nager.   │    │ electron-    │
       │ Date API │    │ store (JSON) │
       └──────────┘    └──────────────┘
```

### 主进程职责
- 定时轮询 Nager.Date API（中国节日）
- 计算倒计时天数
- 存储用户配置和自定义提醒
- 系统托盘图标（右键菜单：设置 / 刷新 / 退出）
- 到时间发送系统通知

### 渲染进程职责
- **贴纸窗口**：无边框、置顶、半透明，常驻桌面角落，显示节日列表 + 倒计时，可拖拽
- **设置窗口**：完整设置界面，打开时贴纸窗口保持运行

## 贴纸窗口设计

无边框、半透明、始终置顶的小窗口，像便利贴一样贴在桌面角落。

- 尺寸：约 280×400px
- 默认位置：屏幕右下角（支持拖拽）
- 半透明背景（磨砂玻璃效果）

### 交互
- 悬停时显示：关闭按钮、置顶切换、刷新按钮

- 双击空白区域刷新数据

## 节日数据获取

### API
[Nager.Date API](https://date.nager.at) — 免费，无需 API Key

```
GET https://date.nager.at/api/v3/PublicHolidays/{year}/CN
```

### 数据流程
1. 应用启动 → 获取当年 + 下一年中国节日列表
2. 缓存到本地（electron-store），每天检查一次：
   - 日期与缓存同一天 → 跳过
   - 否则 → 重新请求当年 + 下一年数据，更新缓存
3. API 请求失败 → 使用本地缓存
4. 无缓存且无网络 → 显示"无法获取节日数据"提示
5. 用户可手动触发刷新

## 自定义提醒

支持四种类型：

| 类型 | 说明 | 示例 |
|------|------|------|
| 一次性 | 指定具体日期，仅提醒一次 | 2026-03-15 |
| 每天重复 | 每天固定时间提醒 | 每天 09:00 |
| 每月重复 | 每月特定日期提醒 | 每月 15 日 |
| 每年重复 | 每年特定日期提醒 | 每年 3 月 15 日 |

每个自定义提醒包含：
- 标题
- 日期 / 重复规则
- 提醒时间
- 提前提醒天数（可选）
- 是否启用

自定义提醒混排在贴纸节日列表中，用不同图标区分：🎉 节日 / 📌 自定义

## 提醒与通知

### 触发机制
主进程每分钟检查一次：
- **节日当天**：当日 08:00 发送"今日是 XX 节"通知
- **自定义提醒**：按重复规则计算下次触发时间，到时间弹通知
- **提前提醒**：用户设置提前天数后，在节日前相应天数发送倒计时通知

### 通知形式
- Electron `Notification` API（Windows 原生通知）
- 点击通知 → 打开设置窗口

## 设置窗口

独立 BrowserWindow，点击系统托盘"设置"打开。

### 设置项

| 设置项 | 说明 |
|--------|------|
| 贴纸位置 | 预设：左上/右上/左下/右下，支持拖拽自定义 |
| 开机自启 | 是否开机自动启动 |
| 提醒开关 | 节日提醒 / 自定义提醒 总开关 |
| 提醒时间 | 每日节日提醒时间（默认 08:00） |
| 提前提醒天数 | 预设（1天/3天/7天）+ 自定义输入 |
| 自定义提醒 | 增删改查，设置标题、日期/周期、提前提醒 |
| API 刷新 | 手动刷新按钮 |

### 布局
- 左侧导航标签（通用 / 提醒 / 自定义提醒）
- 右侧内容区域
- 底部保存按钮

## 错误处理

| 场景 | 处理方式 |
|------|----------|
| API 请求失败 | 使用本地缓存，状态栏显示"离线" |
| 无缓存且无网络 | 贴纸显示"无法获取节日数据，请检查网络" |
| 存储读写失败 | 恢复默认配置，日志记录 |
| 通知发送失败 | 静默失败，不影响主流程 |
